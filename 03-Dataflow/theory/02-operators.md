# عملگرهای Verilog

## دسته‌بندی عملگرها

### عملگرهای محاسباتی

| عملگر | معنی | مثال |
|---|---|---|
| `+` | جمع | `a + b` |
| `-` | تفریق | `a - b` |
| `*` | ضرب | `a * b` |
| `/` | تقسیم | `a / b` |
| `%` | باقیمانده | `a % b` |

### عملگرهای منطقی (Logical)

| عملگر | معنی | مثال |
|---|---|---|
| `&&` | AND منطقی | `a && b` |
| `\|\|` | OR منطقی | `a \|\| b` |
| `!` | NOT منطقی | `!a` |

### عملگرهای بیتی (Bitwise)

| عملگر | معنی | مثال |
|---|---|---|
| `&` | AND بیتی | `a & b` |
| `\|` | OR بیتی | `a \| b` |
| `^` | XOR بیتی | `a ^ b` |
| `~` | NOT بیتی | `~a` |

### عملگرهای کاهشی (Reduction)

روی **همه بیت‌های یک بردار** عمل می‌کنند و یک بیت خروجی می‌دهند:

```verilog
wire [7:0] data;
wire parity  = ^data;   // XOR همه بیت‌ها
wire all_one = &data;   // آیا همه بیت‌ها ۱ هستند؟
wire any_one = |data;   // آیا حداقل یک بیت ۱ است؟
```

### عملگرهای رابطه‌ای

| عملگر | معنی |
|---|---|
| `==` | مساوی |
| `!=` | نامساوی |
| `<` , `>` | کوچکتر/بزرگتر |
| `<=` , `>=` | کوچکتر-مساوی/بزرگتر-مساوی |

### عملگر شرطی (Ternary)

```verilog
assign y = (sel) ? a : b;
// اگر sel برابر 1 باشد y=a وگرنه y=b
```

این عملگر پایه ساخت **Multiplexer** در سطح جریان داده است.

### عملگر الحاق (Concatenation)

```verilog
wire [3:0] a;
wire [3:0] b;
wire [7:0] c = {a, b};      // الحاق دو بردار
wire [7:0] d = {2{a[3:2]}}; // تکرار: بالاترین بیت‌های a دو بار
```

### عملگر شیفت

```verilog
assign y = a << 2;  // شیفت چپ (ضرب در 4)
assign z = a >> 1;  // شیفت راست (تقسیم بر 2)
```

## اولویت عملگرها

از بالاترین اولویت به پایین:

1. `!` , `~` , `+` , `-` (یک‌عملندی)
2. `*` , `/` , `%`
3. `+` , `-`
4. `<<` , `>>`
5. `<` , `<=` , `>` , `>=`
6. `==` , `!=`
7. `&` , `^` , `|`
8. `&&` , `||`
9. عملگر شرطی `?:`

> توصیه: برای جلوگیری از اشتباه همیشه از پرانتز استفاده کنید.

## مثال جامع: یک ALU کوچک

```verilog
module alu_4bit(
    input [3:0] a,
    input [3:0] b,
    input [1:0] op,
    output [4:0] y
);

assign y = (op == 2'b00) ? {1'b0, a + b} :
           (op == 2'b01) ? {1'b0, a - b} :
           (op == 2'b10) ? {1'b0, a & b} :
                           {1'b0, a | b};

endmodule
```

با عملگر شرطی تودرتو، چهار عملیات انتخاب می‌شود.
