# Multiplexer با جریان داده و مقایسه روش‌ها

## Multiplexer چیست؟

Multiplexer (MUX) یک **سیلکتور داده** است: بین چند ورودی، یکی را انتخاب می‌کند و به خروجی می‌فرستد.

- MUX 4 به 1: دو بیت انتخاب `sel`
- MUX 8 به 1: سه بیت انتخاب
- فرمول: MUX 2^N به 1 نیاز به N بیت انتخاب دارد

## روش اول: عملگر شرطی تودرتو

```verilog
module mux_4to1(
    input [3:0] d,
    input [1:0] sel,
    output y
);

assign y = sel[1] ? (sel[0] ? d[3] : d[2])
                   : (sel[0] ? d[1] : d[0]);

endmodule
```

## روش دوم: عملگر شرطی زنجیره‌ای (خواناتر)

```verilog
module mux_4to1_v2(
    input [3:0] d,
    input [1:0] sel,
    output y
);

assign y = (sel == 2'b00) ? d[0] :
           (sel == 2'b01) ? d[1] :
           (sel == 2'b10) ? d[2] : d[3];

endmodule
```

## روش سوم: اندیس‌گذاری بردار (کوتاه‌ترین)

```verilog
module mux_4to1_v3(
    input [3:0] d,
    input [1:0] sel,
    output y
);

assign y = d[sel];

endmodule
```

> این روش ساده‌ترین و بهترین روش برای MUX با تعداد زیاد ورودی است، چون خروجی کامپایلر بهینه‌ترین مدار را می‌سازد.

## MUX با اندازه چند بیتی

برای انتخاب بین **باس‌های داده** چند بیتی:

```verilog
module mux_bus_4to1(
    input [7:0] d0, d1, d2, d3,
    input [1:0] sel,
    output [7:0] y
);

assign y = (sel == 2'b00) ? d0 :
           (sel == 2'b01) ? d1 :
           (sel == 2'b10) ? d2 : d3;

endmodule
```

## مقایسه سه روش

| روش | طول کد | خوانایی | انعطاف |
|---|---|---|---|
| شرطی تودرتو | متوسط | کم | زیاد |
| شرطی زنجیره‌ای | متوسط | زیاد | زیاد |
| اندیس بردار | خیلی کوتاه | زیاد | محدود به ورودی‌های تک‌بیت متوالی |

## تمرین

1. یک MUX 8 به 1 با هر سه روش بنویسید
2. یک MUX 2 به 1 با بیت enable بسازید (اگر enable=0 خروجی 0 شود)
3. با ترکیب دو MUX 4 به 1، یک MUX 8 به 1 بسازید
