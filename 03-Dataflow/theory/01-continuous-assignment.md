# انتساب پیوسته (Continuous Assignment)

## تعریف

در سطح جریان داده، به جای اتصال گیت به گیت، **رابطه بین ورودی و خروجی** را با دستور `assign` توصیف می‌کنیم. کامپایلر خودش مدار منطقی مناسب را می‌سازد.

## ساختار کلی

```verilog
assign خروجی = عبارت منطقی;
```

- سمت چپ همیشه باید یک `wire` باشد (نه `reg`)
- هر وقت ورودی‌ها تغییر کنند، خروجی **بلافاصله** به‌روز می‌شود
- به همین دلیل به آن «پیوسته» می‌گویند

## مثال ساده

```verilog
module and_gate(
    input a,
    input b,
    output y
);

assign y = a & b;

endmodule
```

## تفاوت wire و reg

### wire
- فقط با `assign` یا اتصال به ماژول مقدار می‌گیرد
- مقدار قبلی را نگه نمی‌دارد
- مناسب مدارهای ترکیبی

### reg
- داخل بلوک `always` یا `initial` مقدار می‌گیرد
- حافظه دارد (مثل متغیر در زبان‌های برنامه‌نویسی)
- مناسب مدارهای ترتیبی (بخش ۰۴)

```verilog
wire y;      // ترکیبی
assign y = a ^ b;

reg q;       // ترتیبی
always @(posedge clk)
    q <= d;
```

> نکته مهم: `reg` به معنای «رجیستر سخت‌افزاری» نیست! فقط نوع داده در شبیه‌سازی است.

## مقایسه با سطح گیت

### سطح گیت
```verilog
xor X1(sum, a, b);
and A1(carry, a, b);
```

### سطح جریان داده
```verilog
assign sum   = a ^ b;
assign carry = a & b;
```

هر دو دقیقاً یک مدار می‌سازند، اما نسخه جریان داده کوتاه‌تر و خواناتر است.

## قواعد مهم

1. یک `wire` فقط باید یک منبع داشته باشد (یک `assign`)
2. `assign` داخل `always` نوشته نمی‌شود
3. می‌توان در تعریف پورت، مستقیماً `assign` نوشت:
```verilog
module half_adder(input a, b, output sum, carry);
    assign sum   = a ^ b;
    assign carry = a & b;
endmodule
```

## جمع‌بندی

| ویژگی | سطح گیت | سطح جریان داده |
|---|---|---|
| توصیف | ساختار مدار | رابطه ورودی/خروجی |
| دستور کلیدی | نمونه‌سازی گیت | `assign` |
| طول کد | بلندتر | کوتاه‌تر |
