# پروژه‌های پایانی

## پروژه ۱: چراغ راهنمایی (Traffic Light)

کنترلر چهارفازِ یک تقاطع ساده با تایمر:

```
قرمز (4s) → سبز (4s) → زرد (2s) → قرمز ...
```

### ساختار

- یک شمارنده برای زمان‌گذاری (بر پایه `clk_1hz` فرضی)
- یک FSM چهار حالته
- خروجی‌های `red`, `yellow`, `green`

### نکات طراحی

1. هر حالت یک مدت زمان مشخص دارد → شمارنده `time_cnt` در هر حالت ریست شود
2. هنگام تغییر حالت، شمارنده صفر شود
3. از روش سه‌بلوکی بخش FSM استفاده کنید

## پروژه ۲: فیلتر ضدپرش کلید (Debouncer)

### مسئله

کلیدهای مکانیکی هنگام فشرده شدن چند ده میلی‌ثانیه **نویز پرشی** (Bounce) دارند. اگر مستقیم به شمارنده وصل شوند، یک فشار چند بار حساب می‌شود.

### راه‌حل کلاسیک: نمونه‌برداری با تایمر

```
1. هر 10ms کلید را نمونه‌برداری کن
2. اگر 8 نمونه پشت‌سرهم یکسان بود، وضعیت پایدار است
3. خروجی = وضعیت پایدار
```

### ساختار

- شمارنده سرریز (مثلاً 20 بیت روی ساعت 50MHz → هر ~21ms)
- رجیستر شیفت 8 بیتی برای نمونه‌ها
- وقتی همه بیت‌های شیفت رجیستر یکسان بودند، خروجی به‌روز شود

### ترفند خوانا

```verilog
// اگر همه نمونه‌ها یکسان بود، خروجی همان مقدار است
if (&samples == 1'b1 || &~samples == 1'b1)
    stable <= samples[0];
```

## پروژه ۳ (چالش): ساعت دیجیتال

ترکیب همه آموخته‌ها:

- شمارنده Mod-10 برای ثانیه/دقیقه یکان
- شمارنده Mod-6 برای دهگان
- شمارنده Mod-24 برای ساعت
- خروجی BCD برای نمایشگر سون‌سگمنت

## چک‌لیست پروژه خوب

1. ابتدا **دیاگرام حالت/بلوک** را روی کاغذ بکشید
2. کد را به ماژول‌های کوچک تقسیم کنید
3. برای هر ماژول تست‌بنچ بنویسید
4. خروجی `$monitor` را با مقادیر مورد انتظار دستی مقایسه کنید
5. قواعد `<=` و `=` را دوباره چک کنید
