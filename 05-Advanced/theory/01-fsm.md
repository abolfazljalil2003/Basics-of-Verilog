# ماشین حالت محدود (FSM)

## تعریف

FSM (Finite State Machine) مدل ریاضی محاسبه است که در هر لحظه در **یک حالت مشخص** قرار دارد و با دریافت ورودی، طبق **قواعد انتقال** به حالت بعدی می‌رود. پایه تقریباً همه کنترلرهای دیجیتال است.

## اجزای FSM

1. **حالت‌ها** (States): مجموعه متناهی وضعیت‌ها
2. **ورودی‌ها**: رویدادهای بیرونی
3. **انتقال‌ها** (Transitions): قاعده رفتن از یک حالت به دیگری
4. **خروجی‌ها**: عمل انجام‌شده در هر حالت

## دو نوع FSM

### ماشین Moore
- خروجی **فقط تابع حالت فعلی** است
- خروجی بعد از رسیدن به حالت جدید تغییر می‌کند (یک ساعت تأخیر)
- ساده‌تر برای طراحی و دیباگ

### ماشین Mealy
- خروجی تابع **حالت فعلی و ورودی** است
- خروجی سریعتر (همان لحظه ورودی) اما می‌تواند Glitch داشته باشد

## مثال: تشخیص توالی 1011

می‌خواهیم مداری بسازیم که هر وقت بیت‌های پشت‌سرهم `1011` را دید، خروجی `found` را یک کند.

### دیاگرام حالت (Moore)

```
S0 --1--> S1 --0--> S2 --1--> S3 --1--> S4 (found=1)
S0 --0--> S0        S2 --0--> S0
S1 --1--> S1        S3 --0--> S2   (پسوند 10 حفظ می‌شود)
                    S4 --0--> S2 (پس از 1011، دنباله جدید ممکن است)
                    S4 --1--> S1
```

- S0: هیچ تطبیقی
- S1: `1` دیده شده
- S2: `10` دیده شده
- S3: `101` دیده شده
- S4: `1011` دیده شده → found=1

### روش استاندارد: کد سه‌بلوکی

```verilog
module seq_detector_1011(
    input clk,
    input reset,
    input din,
    output found
);

// --- بلوک 1: رجیستر حالت ---
localparam S0 = 3'd0, S1 = 3'd1, S2 = 3'd2,
           S3 = 3'd3, S4 = 3'd4;

reg [2:0] state, next_state;

always @(posedge clk or posedge reset) begin
    if (reset)
        state <= S0;
    else
        state <= next_state;
end

// --- بلوک 2: منطق حالت بعدی ---
always @(*) begin
    case (state)
        S0: next_state = din ? S1 : S0;
        S1: next_state = din ? S1 : S2;
        S2: next_state = din ? S3 : S0;
        S3: next_state = din ? S4 : S2;
        S4: next_state = din ? S1 : S2;
        default: next_state = S0;
    endcase
end

// --- بلوک 3: خروجی (Moore: فقط تابع حالت) ---
assign found = (state == S4);

endmodule
```

## چرا سه بلوک؟

| بلوک | نوع | انتساب |
|---|---|---|
| رجیستر حالت | ترتیبی | `<=` |
| منطق حالت بعدی | ترکیبی | `=` |
| خروجی | ترکیبی | `assign` یا `=` |

این تفکیک کد را خوانا، دیباگ‌پذیر و قابل‌اعتماد برای سنتز می‌کند.

## نکات مهم

1. از `localparam` برای نام حالت‌ها استفاده کنید، نه ماکرو `define` (خطای scope)
2. همیشه `default` در case بنویسید
3. اگر تعداد حالت‌ها زیاد است، از کدگذاری one-hot یا gray استفاده کنید
4. ورودی‌های ناهمزمان را قبل از ورود به FSM با Flip-Flop همزمان‌سازی کنید (2-FF Synchronizer)

## کاربردهای FSM

- کنترلرهای پروتکل (UART, SPI, I2C)
- چراغ راهنمایی
- ماشین‌های فروش
- کنترل جریان CPU (Fetch/Decode/Execute)
