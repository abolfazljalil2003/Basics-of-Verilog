# موضوعات پیشرفته (Advanced)

در این بخش تکنیک‌های حرفه‌ای Verilog را یاد می‌گیریم: ماشین حالت، حافظه، توابع و پروژه‌های ترکیبی.

## محتوای این بخش

### ماشین حالت محدود (FSM)
- تفاوت Moore و Mealy
- تشخیص‌دهنده توالی (Sequence Detector)
- روش استاندارد سه‌بلوکی طراحی FSM

### حافظه
- RAM همزمان
- ROM با `initial` و `$readmemh`

### توابع و تسک‌ها
- `function` برای محاسبات ترکیبی
- `task` برای عملیات شبیه‌سازی

### پروژه‌های ترکیبی
- چراغ راهنمایی با FSM
- فیلتر ضدپرش کلید (Debouncer)
